# PokeAPIQuiz
PokeAPIを使用したクイズアプリ

# 問題種類
- 名前当てクイズ:表示された画像からポケモン名を当てる
- シルエットクイズ:シルエット画像から名前当て
- 色ちがいクイズ:色ちがいの実在/架空を当てる
- とくせい当てクイズ:とくせいの正娯判断
- ワザ当てクイズ:ワザの正誤判断
- なきごえ当てクイズ:音声からポケモン名の正誤判断
- 身長比較クイズ:二体のポケモンの高低比較
- 体重比較クイズ:二体のポケモンの軽重比較
- 図鑑クイズ:図鑑説明とポケモン名の正誤判断

# モード
- フリーモード:問題種類と世代を自由選択、エンドレス
- 検定モード:制限時間(1問10秒)と問題種類制限
  - 初級:30問、名前当て、シルエット、色ちがい、図鑑
  - 中級:50問、なきごえ、身長比較、体重比較追加
  - 上級:100問、全部

# 画面遷移
タイトルメニュー
├ フリーモード
│ └ 設定画面(世代や問題種類、時間制限の有無など)
│   └ 出題画面
└ 検定モード
  ├ 初級 ┐
  ├ 中級 ├ 出題画面 ─ 結果画面 ─ タイトルへ戻る
  └ 上級 ┘

# 結果画面
- 出題数と正当数で称号表示
- LINE、Xに結果投稿
